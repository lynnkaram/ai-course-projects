# Artificial Intelligence Course Projects

This repository contains four tutorial projects completed for my CPSC 5700 Artificial Intelligence course at Yale University. Each project explores a research paper through a combination of background explanation, practical implementation, and teaching-focused walkthroughs.

## Projects

### 1. LLM-First Search
Explores how large language models can be integrated with classical search methods to improve reasoning and problem-solving.

**Topics:** LLM reasoning, breadth-first search, best-first search, Monte Carlo Tree Search, chain-of-thought reasoning.

### 2. Minimax Q-Learning
Introduces Minimax Q-Learning and multi-step extensions for decision-making in competitive multi-agent environments.

**Topics:** reinforcement learning, Q-learning, minimax methods, Markov games, multi-agent systems.

### 3. Particle Filtering
Demonstrates particle filtering for tracking and prediction, using a soccer player tracking example inspired by research in sport and cognition.

**Topics:** particle filters, probabilistic tracking, state estimation, uncertainty, prediction.

### 4. Promptable Cancer Segmentation
Explores promptable medical image segmentation methods for cancer detection using minimal annotated data.

**Topics:** biomedical AI, medical image segmentation, deep learning, weak supervision, promptable models.

## Skills Demonstrated

- Research paper analysis
- Python programming
- Google Colab notebook development
- Machine learning and artificial intelligence concepts
- Technical communication and tutorial writing
- Biomedical AI and applied AI interpretation
